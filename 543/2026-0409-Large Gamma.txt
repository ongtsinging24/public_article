SpotGamma 核心指標解釋

  ---
  1. Volatility Trigger（波動觸發點）

  定義： 造市商（Dealer）持倉從「正 Gamma」翻轉為「負 Gamma」的臨界股價。

  股價 > Volatility Trigger → 正 Gamma 區
    造市商：「買跌賣漲」→ 市場趨於穩定，波動收斂

  股價 < Volatility Trigger → 負 Gamma 區
    造市商：「買漲賣跌」→ 市場放大波動，趨勢加速

  實戰用法：
  - 這是每日最重要的多空分界線
  - 04-08 PM 更新：Pivot 從 6,600 上移至 6,700
  - 站上 = 多頭環境；跌破 = 波動放大，謹慎

  ---
  2. Zero Gamma Level（零 Gamma 水位 / Gamma Flip）

  定義： 所有到期日的 GEX 加總為零的股價位置。

  Volatility Trigger ≠ Zero Gamma Level

  Volatility Trigger：短線（近期到期）Gamma 翻轉點
  Zero Gamma Level：所有到期日 Gamma 加總翻轉點

  為什麼兩個不同：
  - 短線 Put 密集在某個 strike → Volatility Trigger 在那
  - 但遠期 Call 又在更高位置 → 加總後的零點不同

  實戰用法：
  - 股價在兩者之間 = 過渡區，方向不穩定
  - 04-08 數據：Volatility Trigger 6,600 vs Zero Gamma 6,578
  → 很接近，方向確認度高

  ---
  3. Call Wall（Call 牆）

  定義： Call 選擇權 Open Interest 最集中的 strike，也是 GEX 最大正值的位置。

  機制：
  股價接近 Call Wall
  → 造市商持有大量 Long Call（已對沖買入大量股票）
  → 股價一旦突破，造市商反而需要「賣股」減少對沖
  → 形成天花板阻力

  實戰用法：
  - 短線反彈的第一目標位
  - 突破 Call Wall = 加速上漲訊號（造市商被迫追買更高 strike）
  - 04-08：Call Wall 6,700 → SPX 收 6,783，已突破
  - 突破後 Call Wall 轉為支撐（Pivot 上移至 6,700）

  ---
  4. Put Wall（Put 牆）

  定義： Put 選擇權 Open Interest 最集中的 strike，GEX 最大負值位置。

  機制：
  股價接近 Put Wall
  → 造市商持有大量 Long Put（對沖賣出大量股票）
  → 股價下跌越接近 Put Wall，造市商賣壓越大 (note:股價愈下跌去接近Put Wall)
  → 但一旦跌穿，Put 進入深度 ITM，Delta 趨於 -1
  → 造市商不需要再賣更多股票 → 賣壓反而消失
  → 形成強支撐（反彈點）

  實戰用法：
  - 下跌的最終支撐，也是崩盤後反彈的起點
  - 04-08：Put Wall 6,500（一直未變）
  - 若 SPX 跌至 6,500，預期強力反彈

  ---
  5. Absolute Gamma Strike（絕對 Gamma Strike）

  定義： 單一 strike 上 GEX 絕對值最大的位置（不分正負）。

  = Gamma 最密集、對沖活動最劇烈的 strike

  可能是：
  - 超大 Call OI（正 Gamma）→ 壓制上行
  - 超大 Put OI（負 Gamma）→ 加速下行

  實戰用法：
  - 股價磁吸中心——市場傾向在此附近「盤整」
  - 04-08：Absolute Gamma Strike = 7,000
  → 遠期大量 Call OI 集中，是長線多頭的終極目標區
  - 近期更重要的是 0DTE 形成的局部 Gamma 節點
  （如 04-08 在 6,780 出現 99th %ile 節點）

  ---
  6. SG Implied 1-Day Move（隱含單日波動）

  定義： 根據 ATM 選擇權 IV 計算，市場定價的明日預期波動幅度（±）。

  公式概念：ATM IV ÷ √252 × 股價 = 預期日波動金額

  04-07：ATM IV 35% → Implied Move ≈ ±1.1%（大）
  04-08：ATM IV 17.5% → Implied Move ≈ 0.66%（正常化）

  實戰用法：
  - 判斷明日是否有重大事件風險（數值高 = 市場在定價事件）
  - 做 0DTE 策略時判斷 straddle 合理價格
  - 04-08 PM：0.66%，代表明日（PCE 日）市場預期波動已大幅收窄

  ---
  7. SG Gamma Index（Gamma 指數）

  定義： SG 自製的綜合 Gamma 環境評分，數值代表當前 Gamma 狀態的百分位。

  數值為負 → 整體偏負 Gamma（波動放大環境）
  數值越負 → 危險程度越高

  歷史對照：
    -3.923（03-31）← 最危險，OPEX 前後
    -1.046（04-01）
    -0.508（04-02）
    -0.651（04-07）
    -0.843（04-08 AM 參考價）← 參考價未含跳空
    實際開盤 6,800 後進入正 Gamma

  實戰用法：

  ┌─────────────┬────────────────────┬──────────────┐
  │ Gamma Index │      市場環境      │   操作建議   │
  ├─────────────┼────────────────────┼──────────────┤
  │ > 0         │ 正 Gamma，穩定     │ 可做反彈多頭 │
  ├─────────────┼────────────────────┼──────────────┤
  │ -0.5 ~ 0    │ 過渡區             │ 謹慎，觀望   │
  ├─────────────┼────────────────────┼──────────────┤
  │ -1 ~ -0.5   │ 負 Gamma，波動放大 │ 縮小倉位     │
  ├─────────────┼────────────────────┼──────────────┤
  │ < -1        │ 危險區             │ 以對沖為主   │
  └─────────────┴────────────────────┴──────────────┘

  ---
  七個指標的空間關係圖

  高  ┌─────────────────────────────────────┐
      │  Absolute Gamma Strike（7,000）     │ ← Gamma 最密集，長線目標
      │  Call Wall（6,700）                 │ ← 短線天花板 / 突破後轉支撐
      │  Zero Gamma Level（6,578）          │ ← Gamma 翻轉線
      │  Volatility Trigger（6,600）        │ ← 多空分界，最重要

      SG Implied Move：明日預期波動幅度

● 這兩個指標在 PDF 報告中標示為 SPX Levels 和 SPX Combos，讓我根據資料模式解釋：

  ---
  Large Gamma 1～3

  定義： 單一 Strike 上 GEX 絕對值最大的前 3 個位置（不分正負）。

  = Absolute Gamma Strike 的「前 3 名排行榜」

  Absolute Gamma Strike：只給你第 1 名
  Large Gamma 1~3：給你前三名完整清單

  從 PDF 看到的實際數據（04-08）：
  SPX Levels: [7000, 6000, 6600, 6700]
  → 這 4 個就是 Large Gamma 最高的幾個位置

  實戰含義：
  - 每個都是價格磁吸點，股價容易在附近停留或被吸引
  - 正 Gamma 的 → 天花板阻力（6,700 / 7,000）
  - 負 Gamma 的 → 跌穿後加速下行（6,000）
  - 三個加在一起描繪出完整的「價格引力場」

  ---
  Combo 1～4

  定義： 跨越多個到期日、多個 Greek 維度同時收斂的 Strike，是「複合影響力」最強的 4 個位置。

  從 PDF 看到的實際數據（04-08 格式）：
  SPX Combos:
  (6903, 84.08), (6876, 73.19), (6850, 74.69) ...
  (6526, 92.49), (6499, 98.12), (6473, 92.40) ...
  → 第一個數字是 Strike 價格，第二個數字是複合強度分數（0~100）

  分數越接近 100 = 該 Strike 的複合影響力越強

  ---
  Combo 分數的構成邏輯

  Combo 分數整合了以下多個維度：

  ┌─────────────────┬────────────────────────────────────────────┐
  │      維度       │                    說明                    │
  ├─────────────────┼────────────────────────────────────────────┤
  │ 跨期 Gamma 疊加 │ 多個到期日在同一 Strike 有大量 OI          │
  ├─────────────────┼────────────────────────────────────────────┤
  │ Delta 暴露      │ 該 Strike 的整體 Delta 量                  │
  ├─────────────────┼────────────────────────────────────────────┤
  │ Vanna 效應      │ IV 變化時對 Delta 的敏感度                 │
  ├─────────────────┼────────────────────────────────────────────┤
  │ Put + Call 雙向 │ Put 和 Call 都有大量 OI 的 Strike 分數更高 │
  └─────────────────┴────────────────────────────────────────────┘

  直觀理解：
  普通 Strike：只有某一到期日的 Call 集中
  Combo Strike：同時有近期 + 遠期的 Call 和 Put 都密集
                → 多重力量同時作用在同一個價格點
                → 造市商在此的對沖行為最複雜

  ---
  Large Gamma vs Combo 的差異

  ┌──────────┬────────────────────────────┬────────────────────────────┐
  │   指標   │      Large Gamma 1~3       │         Combo 1~4          │
  ├──────────┼────────────────────────────┼────────────────────────────┤
  │ 衡量什麼 │ 單一維度（GEX 最大）       │ 多維度（跨期 + 跨 Greek）  │
  ├──────────┼────────────────────────────┼────────────────────────────┤
  │ 數量     │ 前 3 名                    │ 前 4 名（含分數）          │
  ├──────────┼────────────────────────────┼────────────────────────────┤
  │ 用途     │ 找最強的單一阻力/支撐      │ 找「多重力量交會點」       │
  ├──────────┼────────────────────────────┼────────────────────────────┤
  │ 出現位置 │ 常是整數關卡（6700、7000） │ 可能是非整數的「隱形關卡」 │
  └──────────┴────────────────────────────┴────────────────────────────┘

  ---
  實戰使用方式

  Large Gamma → 確認大方向的關鍵價位
                （是否在 6,700 上方？是否守住 6,000？）

  Combo      → 找日內交易的精確支撐/壓力
                分數 > 90 的 Combo Strike 特別重要
                股價接近時，觀察 HIRO 方向作為進出依據

  04-08 的 Combo 分數高位 Strike：
  6,499（98.12）← 接近滿分，極強支撐
  6,526（92.49）← 次強
  6,473（92.40）← 跌穿後的下一個重要關卡
  → 這些位置比「圓整數字」更精確地描述了真實的 Gamma 聚集點。
