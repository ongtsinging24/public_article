# ROMA 術語：「制度信號」與「市場信號」並非同義

**日期**：2026-04-22
**場景**：TG Bot 推送警報時出現「⚡ 制度信號」與「💡 市場信號綜合研判」兩個標題，釐清兩者差異與對應英文。

---

## 縮寫
- **GEX** Gamma Exposure｜**Dealer** 做市商｜**regime** 制度/體制
- **synth_oi** SpotGamma 合成 OI 資料源｜**v4** SpotGamma 真實 Dealer gamma 資料源
- **SPY/QQQ** 標普 500 / 納斯達克 100 ETF

---

## 一、結論先說

**不同義**。兩個是 ROMA 系統中的**兩個獨立分析層**，出現在不同場景、用不同資料源、回答不同問題。

| 概念 | 英文 |
|------|------|
| 制度信號 | **regime signal** (Gamma regime signal) |
| 市場信號綜合研判 | **market signal** / market signal verdict |

## 三、語義本質

### 制度信號（Regime Signal）— 描述「遊戲規則」

回答：**市場目前處於什麼 Gamma 結構下？**
- Negative Gamma regime：dealer 短 gamma → **追漲殺跌**（助漲助跌，波動放大）
- Positive Gamma regime：dealer 長 gamma → **吸震**（買低賣高，波動壓縮）

這是**結構面/環境面**資訊，告訴你「場地是什麼地形」。它不給方向建議，只描述「當前遊戲規則」。

**生成機制**（`sg_opportunities.py:95-112`）：
```python
regime_signals = []
# 掃描 SPY / QQQ / NDX 等指數的 v4 Call+Put Gamma
# 若 Net GEX < 0 且達到門檻 → 觸發 negative_gex_regime / negative_gex_high_ratio
# regime_signals 不 cooldown — 市場環境評估應每次反映當下制度
```

### 市場信號綜合研判（Market Signal Verdict）— 給出「走向結論」

回答：**綜合看多還是看空？應該做什麼？**

生成機制（`sg_spy_qqq.py:398-413`）：
```python
avg_score = (spy_score + qqq_score) / 2   # 10 維度 synth_oi 評分均值
if   avg_score >=  6: "🚀 強勢多頭結構：…建議：維持/加碼核心多頭"
elif avg_score >=  2: "📈 偏多結構：…建議：持有既有多頭，謹慎加倉"
elif avg_score >= -1: "⬛ 中性/震盪：…建議：降低方向性押注"
elif avg_score >= -4: "📉 偏空結構：…建議：縮減敞口，增加 Put 保護"
else:                 "🩸 強勢空頭結構：…建議：全面防禦"
```

這是**方向面/決策面**結論，把量化評分（+8、-4 等）翻譯成自然語言建議。

## 四、兩者如何互補

在 `/scan SPY` 輸出中，你會**同時**看到兩者：

```
📊 SPY 趨勢估評
...
🔬 維度評分明細（-2 ~ +2）
  ...（10 項評分）

💡 市場信號綜合研判             ← 市場信號（給方向）
  📈 偏多結構：…可逢低加倉

...

🎯 SPY Dealer Gamma 行為預測
⚙️ GEX 制度判定                 ← 制度信號（給結構）
  Net GEX：$-3.80B
  制度：🔴 Negative Gamma — dealer 追漲殺跌，波動放大
```

**互補關係**：
- 制度信號 = 地形圖（負 gamma → 今天可能會暴衝/暴跌，要抓波動）
- 市場信號 = 路線建議（偏多 → 往上走的機率較高）

舉例：
- 偏多 + Negative Gamma → 上漲可能劇烈放大（squeeze）但也可能快速翻轉 → **方向對但要用 buy premium 而非 short vol**
- 偏多 + Positive Gamma → 上漲緩慢吸震 → **可賣 vol 收 theta**
