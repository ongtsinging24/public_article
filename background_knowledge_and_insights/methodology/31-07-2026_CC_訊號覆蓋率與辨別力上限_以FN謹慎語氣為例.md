- 產出：2026-07-31（台北）

- 類型：方法論（**常青**）＋ §3 的覆蓋率數字有時效
- 腳本：`py_dir/31-07-2026_fn_tone_persistence.py`

**縮寫對照**：FN=Founders Note (SpotGamma)｜SG=SpotGamma｜覆蓋率(fire rate)=訊號成立的樣本比例｜辨別力(discrimination)=條件組與對照組的結果差異｜補集(complement)=訊號不成立的那些樣本｜CI=信賴區間｜Wilson CI=小樣本比例的信賴區間｜T+1/T+5=之後 1/5 個交易日報酬｜put fly=賣權蝶式（偏空的限定風險結構）｜core long=核心多頭部位｜0DTE=當日到期

## 一、理論框架（本篇的常青部分）

### 覆蓋率壓縮辨別力 —— 一條恆等式

設某訊號覆蓋率 `p`，條件組平均結果 `C`，補集平均結果 `N`。全樣本基準 `B` 必然是兩者的加權平均：

```
B = p·C + (1-p)·N
```

因此**你在報表上看到的「條件組 vs 全樣本基準」的落差**是：

```
C - B = (1-p)·(C - N)
```

**關鍵推論：真實的辨別力 `(C-N)` 會被 `(1-p)` 這個係數壓縮後才呈現。**

| 覆蓋率 p | 壓縮係數 (1-p) | 意義 |
|---|---|---|
| 50% | 0.50 | 落差如實反映一半 |
| 80% | 0.20 | 真實差異要 5 倍大才看得出來 |
| **85%** | **0.15** | **真實差異要 6.7 倍大才看得出來** |
| 95% | 0.05 | 20 倍 —— 實務上不可能測到 |

→ **覆蓋率 >80%（或 <2%）的訊號，在合理樣本量下幾乎不可能測到可用的 edge。** 這與訊號對不對無關，是統計結構決定的天花板。

### 兩條操作守則

1. **評估任何訊號之前，先算它的覆蓋率。** 覆蓋率極高的「訊號」其實是**背景常數**，不是訊號。
2. **覆蓋率高時，對照組必須用補集（complement）而非全樣本。** 當 p=0.85，全樣本裡有 85% 就是條件組本身 —— 拿全樣本當基準等於**拿自己比自己**，必然看不出差異。
   → 這是對 [[feedback_hitrate_needs_conditional_baseline]]（禁用 50% 當隨機基準）的細化：**基準不只要是條件基準，當覆蓋率高時還必須是補集基準。**

**恆等式驗算**：p=0.847 → 壓縮係數 0.153。實測 `C-B` = 0.05-0.02 = **0.03pp**，反推 `C-N` = 0.03/0.153 ≈ **0.20pp**；直接計算 `C-N` = 0.05-(-0.19) = **0.24pp**。兩者一致（差異來自四捨五入）→ **§1 的恆等式在本樣本成立。**

⚠️ **n=7、CI [8%, 64%] 橫跨全樣本基準 51.9% → 無法檢定，不可交易。** 只記為線索。這與 [[30-07-2026_CC_HIRO日終淨值非隔夜方向訊號]] 的拆解假說、[[31-07-2026_CC_軟體vs半導體脫鉤極端度與共漲三關檢定]] 的離群 flip 假說是同一種下場：**細分層一旦切下去，樣本就不夠了。**

## 五、結論與行動

1. **覆蓋率先算，再談 edge。** 訊號覆蓋率 >80% 或 <2% 時，(1-p) 壓縮會讓真實差異需要放大 5~20 倍才測得到 —— 這種「訊號」是背景常數。

2. **高覆蓋率訊號的對照組要用補集，不是全樣本。** 否則是拿自己比自己。

3. **SG 的謹慎語氣是背景雜訊，不是訊號**（85% 覆蓋率、T+1/T+5 與基準完全重疊）。讀 FN 時**跳過形容詞**，只抓三樣：
   - **水位數字**（Pivot / Resistance / Support）
   - **gamma 結構位置**（負 gamma 口袋在哪、0DTE 支撐何時蒸發）
   - **他們自己開的倉**（put fly / call fly / core long）

4. **SG 的價值分層**（與 [[31-07-2026_TRENDFN]] §4 記分板一致，現有統計基礎）：

| SG 產出 | 記分（2026-07 窗口） | 用不用 |
|---|---|---|
| 結構／定價判讀 | **4/4** | ✅ 用 |
| FlowPatrol 選標 | **2/2** | ✅ 用（但查 IV 貴賤） |
| 方向性短打 | 0/1 | ❌ 不用 |
| **「小心」的語氣** | **85% 覆蓋、零辨別力** | ❌ **當背景雜訊** |

   → 細化 [[feedback_data_source_priority]]：**不只「SG 優於博主」，在 SG 內部也要分層 —— 結構化水位 > 自營部位 > 散文語氣。**

5. **要追蹤的是有門檻的承諾，不是形容詞。** 2026-07-30 是本樣本少數的雙向 note（bear=4, bull=4），且首次寫下可證偽的翻多條件：
   > "**If/when positive gamma comes back into the SPX, we will look to re-establish core long positions.** Until then, we will play upside with call spreads and/or flies."

   **這句有門檻（SPX 回正 gamma ≈ ≥7,500）、可證偽、可追蹤 —— 這才是 FN 值得抄下來的東西。**
