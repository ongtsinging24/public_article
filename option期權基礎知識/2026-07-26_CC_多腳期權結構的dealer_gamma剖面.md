## 2. 理論框架

### 2.1 既有的單腳層（已被 [[kb_put-wall-support-mechanics]] 覆蓋，本篇不重複）

單腳的符號分水嶺已經是定案：

```
客戶【賣】put → dealer LONG put  → 正 Γ → 跌買漲賣 → 壓抑波動 = 支撐
客戶【買】put → dealer SHORT put → 負 Γ → 跌賣漲買 → 放大波動 = 加速器
```

`26-07-2026-MarketMaker_GAMMA.md` 全篇講的就是這一層的四種排列組合，講得正確。

### 2.2 本篇要補的：**多腳結構會讓 dealer 的 Γ 符號沿價格軸變號**

單腳分析回答「dealer 現在是正 Γ 還是負 Γ」——一個**狀態**。
多腳結構要回答的是「dealer 的 Γ 在**不同價位**分別是什麼符號」——一個**剖面**。

BePS 575/520 拆給 dealer 之後：

```
        575（dealer SHORT put）        520（dealer LONG put）
        ↓                               ↓
   ─────●───────────────────────────────●─────  價格軸
        負 Γ 密度源                      正 Γ 密度源
        「加速踏板」                      「剎車」
```

關鍵在於 **Γ 是 ATM 最大、往兩側衰減**。所以當價格從 575 往 520 移動：

- 575 那腳越走越深 ITM → 它的 Γ **衰減** → dealer 的負 Γ 貢獻**變弱**
- 520 那腳越走越接近 ATM → 它的 Γ **升高** → dealer 的正 Γ 貢獻**變強**

兩者必然在某個價位交叉。**dealer 的淨 Γ 會在下跌途中由負翻正。**
這不是經驗法則，是 Γ 曲線形狀的恆等結果。

### 2.3 必須分離的兩件事（本次糾正的核心誤解）

最容易混淆的一點：**把「初始 Δ 對沖」和「後續 Γ 對沖」黏成同一件事**，
於是得出「dealer 負 Γ ⇒ 偏空」的錯誤結論。

| | 性質 | 有方向嗎 | 持續嗎 |
|:---|:---|:---|:---|
| **初始 Δ 對沖** | 建倉當下砸一筆 | **有**（機構買 put → dealer 放空） | ❌ 一次性 |
| **後續 Γ 對沖** | 價格每動就再平衡 | **沒有**（雙向對稱放大） | ✅ 持續 |

**負 Γ 本身不含任何向下偏向。** 在負 Γ 區，跌會跌更兇，漲也會漲更兇（軋空同樣暴力）。
原文的比喻其實下對了：「斜坡上的球」＝**推哪邊往哪邊滾**，不是「往下滾的球」。

負 Γ 環境確實常伴隨大跌，但成因在別處，不在 Γ 的符號：
① 初始 Δ 對沖流本身向下；② put skew 使下方 Γ 密度本來就較厚；
③ 跌時 IV 上升（vol-of-vol）；④ 恐慌時真的有人在追買 put。
**Γ 只放大「已經發生的動作」，不決定往哪動。**

## 3. 試算設計

- **標的**：SMH ＝ $561.19（2026-07-24 週五收盤，yfinance；整理日 2026-07-26 為週日休市）
- **結構**：機構 BUY BePS 575/520 → dealer = short 575P + long 520P
- **參數**：IV = 0.5627（SG data_table 2026-07-26「1 M IV」欄）、r = 4%、q = 0
- **腳本**：`py_dir/2026-07-26_beps_dealer_gamma_profile.py`

⚠️ **試算限制（三項，勿當精確值用）**：
1. **到期日未知** → 用 30/45/60/90 DTE 做敏感度，不挑單一值。
2. **用平坦 IV**。⚠️ **2026-07-26 當日實算修正**——原本推測「skew 會讓變號點上移、更早剎車」，**方向錯了**。
   接上 broker log 的真實 σ（575P 0.55 / 520P 0.61）後：

   | | 淨 Δ @DTE28 | Γ 變號點 @DTE28 | Γ 變號點 @DTE45 |
   |:---|---:|---:|---:|
   | 平坦 IV 0.5627 | −0.2446 | $538 | $533 |
   | **真實 skew 55/61** | **−0.2354** | **$526** | **$513** |

   - 淨 Δ 確實**略小**（這部分原推測正確），且 −0.2354 與 broker log 的 **Δnet = −0.24 對得上**，驗證本腳本。
   - 但 **Γ 變號點是往下移、不是往上**。原因：下腳 IV 較高會把它的 Γ 峰值**壓矮攤平**，
     使它在接近自身履約價時的 Γ 貢獻不如平坦 IV 假設那麼陡 → **剎車比平坦 IV 預期的更晚啟動**。
   - ⇒ **平坦 IV 試算在「剎車點」上是偏樂觀的**（會高估地板位置），引用時務必用帶 skew 的數字。
3. **單一結構孤立計算**。真實盤面是整條 chain 加總，見 §5.1。

## 4. 結果

### 表 1：dealer 初始淨 Δ ＝ 兩腳相減，只有裸買的三~四成

| DTE | Δ(575P) | Δ(520P) | dealer 淨 Δ | 佔裸買 575 的比例 |
|---:|---:|---:|---:|---:|
| 30 | −0.5198 | −0.2831 | **+0.2367** | **45.5%** |
| 45 | −0.4997 | −0.3052 | **+0.1945** | **38.9%** |
| 60 | −0.4855 | −0.3167 | **+0.1688** | **34.8%** |
| 90 | −0.4649 | −0.3271 | **+0.1378** | **29.6%** |

> dealer short 575P → Δ 貢獻 = −Δ(575P)（正）；dealer long 520P → Δ 貢獻 = +Δ(520P)（負）。
> **淨 Δ 為正 → dealer 放空現貨/期貨避險 → 建倉當下確有向下賣壓**，但量只有同名目裸買 put 的 **30~45%**。
> **DTE 越長，價差的自我對沖越徹底**（90 DTE 只剩 29.6%）——長天期 BePS 對盤面的即時衝擊很小。

### 表 2：dealer 淨 Γ 沿價格軸的變號（DTE = 45）

| 價格 | Γ(575P) | Γ(520P) | dealer 淨 Γ | 判讀 |
|---:|---:|---:|---:|:---|
| 600 | 0.003177 | 0.002349 | −0.000828 | 加速（助漲助跌） |
| 580 | 0.003433 | 0.002769 | −0.000663 | 加速 |
| **560** | 0.003605 | 0.003184 | **−0.000422** | 加速 ← **現價 561.19** |
| 550 | 0.003652 | 0.003379 | −0.000274 | 加速 |
| 540 | 0.003669 | 0.003558 | −0.000111 | 加速（已近變號） |
| **530** | 0.003654 | 0.003719 | **+0.000064** | **剎車（高拋低吸）** |
| 520 | 0.003605 | 0.003853 | +0.000248 | 剎車 |
| 500 | 0.003406 | 0.004027 | +0.000621 | 剎車 |
| 480 | 0.003078 | 0.004043 | +0.000965 | 剎車 |

**→ Γ 變號帶落在 $530~$540（約 $535）。**

這是本篇最反直覺的一項：**剎車不是在短腳 520 才啟動，而是在兩腳中點附近（$547.5 的略下方）就開始。**
到達 520 時 dealer 早已深在正 Γ 區、已經買了一路。
換句話說，**BePS 的「地板」比它的短腳履約價更高、更寬**。

### 表 3：BePS vs 裸買 put 的盤面含意

| | 裸買 575 put | BePS 575/520 |
|:---|:---|:---|
| 初始賣壓 | 全額 | **30~45%** |
| 下跌時 dealer Γ | 一路負，**越跌越猛** | 負 → **~$535 翻正** → 自帶剎車 |
| 盤面幾何 | 下方**懸崖** | 下方**走廊**（有底） |
| 訊號解讀 | 「我要保護/做空，無下限」 | 「我預期跌到 520，**且不預期破 520**」 |

**機構選 BePS 而非裸買 put，本身就是在宣告一個下檔目標區間。**
而 dealer 的機械對沖會把這個宣告**實現成真實的盤面結構**：上緣加速下滑、下緣煞停。
訊號與結構在此處自我實現——這是 BePS 值得單獨追蹤的理由。

- **PW 與 KG 都正好在 520**，與假設的短腳位置重合。
- 現價 561.74 **在 HW 590 之下** → 依 VT 口徑處於**負 Γ regime**；
  Call Gamma 與 Put Gamma **雙負**，兩個口徑一致，無 `_regime_caveat` 分歧。
- Put Vol 是 Call Vol 的 6.9 倍、IVR 0.95 → 確實滿場在買 put。

> 📌 **HW ≡ VT**：SG UI 把 Vol Trigger 改名為 Hedge Wall，跨檔驗證 MO idx4 ≡ data_table
> `Hedge Wall` 6/6 指數標的全中（[[kb_zg-vt-inversion-signed-gap]]:9,25）。
> 所以「現價在 HW 之下 ⇒ 負 Γ regime」是合法推論，HW 不是普通牆位而是 regime 權威線。

### 5.2 ⚠️ 因果方向：不要說「機構賣 520 造出了 PW」

單一機構的一條腳撐不起一道牆。**比較常見的是反過來**——機構把短腳掛在 520，
是因為那裡本來就是 OI 最厚、流動性最好的位置。PW 是**整條 chain 加總**的結果
（正是 `26-07-2026-MarketMaker_GAMMA.md` 附錄第 1 點在講的「淨部位 vs 單口」）。

同理，§4 表 2 算的是**這個結構孤立看**的 Γ 剖面。真實 dealer 淨 Γ 還要疊加全市場其他部位；
SMH 目前整體是負 Γ，所以 520 附近的正 Γ 是**負 Γ 汪洋裡的一座島**，不是全域狀態。

### 5.3 ⚠️ 實證缺口：「PW = 支撐」在我方資料上**尚未被證實**

ROMA 自己的回放已經標注這個問題：
`romasys/src/opportunities/sg_signals/put_wall_band_replay.py:23-26` —
> 「B3 regime 依賴：band 效應是不是只在正 dealer gamma 出現？若是，本項撞『負 gamma regime 牆』
> （feat_phase2 2026-07-06 回放：**73/73 approach 全負 gamma**）⇒ 觀察層可以先上，
> 但**不得**宣稱它有支撐含義。」

**樣本 73/73 全部落在負 Γ regime → PW 支撐效應與 regime 完全共線，無法區辨。**
所以本篇 §2、§4 的機制推導是**恆等式層面成立**，但「機制成立」≠「盤面上量得到」。
引用本篇時請保持這個區分，不要拿 §4 的表去宣稱勝率。

## 6. 結論與行動

1. **負 Γ 是對稱放大器，沒有方向偏好。** 看到「負 Γ ⇒ 偏空」的說法一律當成誤讀。
   要講方向，講的必須是**初始 Δ 對沖流**（一次性），不是 Γ。
2. **價差結構的初始衝擊 = 兩腳相減**，只有同名目裸買的 **30~45%**，且 DTE 越長越小。
   看到大額 BePS 不要按裸買的量去估盤面衝擊。
3. **多腳結構給的是「區間」不是「方向」。** BePS 的 dealer Γ 在 **~兩腳中點略下方**由負翻正，
   下緣自帶剎車。讀 BePS 要讀成「下檔走廊」，不是「下檔懸崖」。
4. **實務順序**：先 `dir=` 覆核 → 再拆腳 → 再算剖面 → 最後才疊回全市場淨 Γ 與 VT/HW regime。
   跳過第一步的話，整套推論可能整個反過來。
