## 一、投資命題

LAC 幾乎是一張 Thacker Pass 的單一資產票。市場不是在買目前盈利，而是在押：

1. Phase 1 能否在 **2027 年底 mechanical completion**；
2. 2028 commissioning／ramp 能否使 2029 接近 40ktpa full rate；
3. 更新後 Phase 1 CAPEX 是否仍接近原 **$2.93B**；
4. 長期碳酸鋰實現價能否維持約 **$20k–21k/t**；
5. DOE／GM／Orion／Yorkville／ATM 帶來的資金支持，是否會被股本稀釋抵消。

**一句話**：DOE 和 GM 大幅降低「項目活不下來」的尾部風險，但沒有消除 commodity-price risk、first-of-kind ramp risk 或普通股稀釋。

## 十一、100% 集中持有 LAC 的組合風險（朋友案例）

> 情境：朋友把目前美股的全部倉位放在 LAC。以下要先區分「美股子帳戶 100%」與「全部可投資資產 100%」；兩者的實際財務風險完全不同。

### 11.1 核心裁決

**如果 LAC 是全部可投資資產，我認為不可接受；如果只是佔總資產很小的娛樂／投機帳戶，才可能合理。**

問題不一定是 LAC 資產品質差，而是 **100% LAC 的 portfolio construction 很差**。一張股票實際同時集中押注：

1. 單一項目 Thacker Pass；
2. 單一商品 lithium；
3. 單一大型施工及 commissioning 計畫；
4. 尚未在商業規模證明的 claystone processing；
5. DOE／GM／Orion／Yorkville／ATM 共同構成的複雜資本結構。

這些風險還會互相強化：

> 鋰價下跌 → 股價下跌 → 融資條件惡化 → 低價增發／浮動價轉股增加 → fully diluted shares 上升 → 每股 NAV 再下降。

因此 100% 倉位不是單純「高 conviction」，而是接受高度相關的 commodity、construction、financing、dilution 和 execution risk 一起發生。

### 11.2 為甚麼本卡估值不支持 all-in

以 §八 Phase 1-only 情境對照 $3.02：

| 情境 | NAV/share | 對 $3.02 的含義 |
|---|---:|---:|
| 壓力：$12k/t、CAPEX +20% | 接近 $0，只餘 option value | 可能 −70% 至接近全損 |
| 基準：$18k/t、CAPEX +10% | 約 **$1.7** | 約 **−44%** |
| 樂觀：$24k/t、無超支 | 約 **$5.1** | 約 **+69%** |

這不是預測股價一定跌到 $1.7；Phase 2–4、85 年礦命及美國戰略性另有 option value。但它證明 $3.02 並非只要項目存活便能獲利，仍要求部分正面假設成立。

100% 倉位還有 path risk：若 $3.02 先跌 70% 至約 $0.91，往後需上升約 **232%** 才回本。即使長期方向判斷最後正確，也可能因短期資金需求、心理壓力或低價融資而無法持有至終局。

### 11.3 先判斷「全部倉位」的分母

| 實際情況 | 判斷 |
|---|---|
| 美股帳戶只佔總資產 2%–5%，另有現金／退休資產／收入 | 可視為 venture-style speculative allocation |
| LAC 是全部流動投資，但另有穩定收入及緊急預備金 | 仍非常激進，應降低集中度 |
| 緊急金、未來 2–3 年支出或借貸資金也在 LAC | 🔴 不可接受，應先處理財務生存風險 |
| 使用 margin、賣裸 put 或借款加碼 | 🔴 禁止；融資與標的下跌會形成同向強平風險 |

成本價不是處置依據。**「等回本再分散」是心理錨，不是風險管理**；市場不知道投資者成本。

### 11.4 建議的集中度尺標

| LAC 佔全部可投資資產 | 本卡裁決 |
|---|---|
| **2%–5%** | 合理 speculative satellite；能承受全損 |
| **5%–10%** | 高 conviction 上限區，須有完整生活緩衝 |
| **10%–15%** | 非常激進，必須有明確 risk budget |
| **>20%** | 單一項目風險已主導整個組合 |
| **100%** | 不是一般投資配置，而是單一項目押注 |

即使只保留 10%：若 LAC 上漲三倍，仍可對整體資產貢獻約 +20%；若接近歸零，組合仍可生存，並保留 mechanical completion／qualification 後再加碼的選擇權。**沒有必要用 100% 倉位才能從 bull thesis 獲益。**

### 11.5 若已經 100%，如何降低風險

在不知道朋友成本、稅務、總資產與現金需求前，不替他們指定一個精確賣出比例；但若 LAC 是重要資產的 100%，原則是：

1. **先立即降低一部分集中度**，不要把全部處置寄託於下一次 CAPEX 公告；
2. 釋放的資金放現金／短債／廣泛指數，不要換成另一隻單一高波動股票；
3. 剩餘部位依 T1–T10 管理，尤其 CAPEX >$3.3B／工期失守時繼續降；
4. 若低價 ATM 或 Yorkville 浮動價轉換增加，立刻以新 fully diluted shares 重算 NAV；
5. 不用 covered call 偽裝已分散——它限制上行但沒有消除項目失敗的 downside；
6. 不使用 margin、借貸或 naked put 增加曝險。

### 11.6 對朋友最值得說的一句

> **可以非常看好 LAC，但沒有必要把生存權也押上去。好資產不等於任何價格都值得買，也不等於適合佔投資組合 100%。**

若這是朋友的全部財務資產，應先處理集中度，再討論 LAC 方向。對 pre-revenue、單項目、資本密集型公司，**能承受近乎全損而不影響生活的倉位，才是合適倉位。**
