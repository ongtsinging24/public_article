- 類型：**方法論（常青）**＋ §3 的具體數字有時效（2026-07-30 當日報酬）
- 腳本：`py_dir/05-08-2026_reverse_engineer_principal_from_daily_pnl.py`

| AVGO | Broadcom Inc.（個股） |
| VOO | Vanguard S&P 500 ETF（大盤） |
| **N** | principal，欲反推的部位規模（本金 / NAV） |

## 一、理論框架

### 1-1 基本恆等式

單日組合盈虧是各腿盈虧之和，各腿盈虧 = 該腿市值 × 該腿報酬：

```
ΔP&L = Σ_i ( N · w_i · r_i )  =  N · Σ_i ( w_i · r_i )  =  N · r_port

⇒  N = ΔP&L / r_port
```

這是個**除法反演**（inversion）。除法反演的所有病理都適用：**分母越小，反推結果越不穩定、誤差放大越嚴重**。這是本篇最重要的一句話。

### 1-2 誤差放大的量化

對 `N = ΔP&L / r` 取對數微分：

```
dN/N  =  d(ΔP&L)/ΔP&L  −  dr/r
```

- 分子誤差（盈虧金額）**線性**傳遞：報 10 萬還是 12 萬，本金就差 20%。
- 分母誤差（組合報酬）**以 1/r 放大**：r 越接近 0，同樣 ±0.1pp 的報酬誤差造成的本金誤差越大。

| r_port | 反推本金（ΔP&L=$100K） | r 誤差 ±0.1pp ⇒ N 誤差 |
|---:|---:|---:|
| 0.20% | $50,000,000 | **±66.7%** |
| 0.50% | $20,000,000 | ±20.8% |
| 1.00% | $10,000,000 | ±10.1% |
| 2.00% | $5,000,000 | ±5.0% |
| **3.20%** | **$3,127,000** | **±3.1%** ← 本案 |
| 5.00% | $2,000,000 | ±2.0% |

**適用性判準：`|r_port| ≳ 2%` 這個方法才有意義。** 平淡的一天（r < 0.5%）反推出來的本金是雜訊，不是估計。本案 r=3.20% 落在可用區間，這是它能回答的前提條件——不是每個「今天賺了 X 元」都能反推。

### 1-3 為什麼要有這個框架（不只是算術）

問題表面是一道除法，但它藏了三個**口徑選擇**，每個都能把答案改動 10–100%：

| 陷阱 | 誤選的後果 | §對應 |
|---|---|---|
| **① 權重口徑**：成本權重 vs 市值權重 | 恆等式只吃市值權重；用成本權重會高估本金 | §4-1 |
| **② 日期口徑**：哪一個 session | 同一週內選錯一天，答案 $2.4M ↔ $54M | §4-2 |
| **③ 精度口徑**：「超過 10 萬」是下限、1 位有效數字 | 報出 7 位數的精確值＝偽精度 | §4-3 |

## 二、實驗設計

- **資料源**：yfinance 日線收盤，`auto_adjust=False`，區間 2026-07-20 → 2026-08-04（11 個交易日）
- **假設**：純現股、無當日交易、無槓桿/期權、無股息落帳；ΔP&L 為未實現市值變動
- **基準情境**：w_AVGO = 50%（市值權重）、ΔP&L = $100,000、日期 = 2026-07-30
- **敏感度掃描**：權重 30%–75%（每 5pp）、成本權重情境 5 組、樣本期內每個 session、ΔP&L 10.0–14.9 萬

## 三、結果

### 3-1 標的日原始數據（2026-07-30）

| 標的 | 07-29 收 | 07-30 收 | 日報酬 |
|---|---:|---:|---:|
| AVGO | 370.32 | 387.84 | **+4.731%** |
| VOO | 670.63 | 681.79 | **+1.664%** |
| — | | spread | **+3.067 pp** |

```
r_port = 0.5 × 4.731% + 0.5 × 1.664% = 3.1976%
N      = $100,000 / 0.031976 = $3,127,373
```

**⇒ 答案：約 $3.1M（≈ NT$9,400 萬），且因 ΔP&L 是下限，N 亦為下限。**

### 3-2 權重敏感度

| w_AVGO | r_port | 反推本金 | vs 50/50 |
|---:|---:|---:|---:|
| 30% | 2.584% | $3,869,693 | +23.7% |
| 40% | 2.891% | $3,459,157 | +10.6% |
| **50%** | **3.198%** | **$3,127,373** | — |
| 60% | 3.504% | $2,853,665 | −8.8% |
| 70% | 3.811% | $2,624,011 | −16.1% |

彈性：w_AVGO 每 +10pp → r_port +0.307pp（相對 +9.6%）→ 本金 −8.8%。**約 1:1 的溫和彈性**，因為兩腿 spread 只有 3.07pp。若兩腿是「個股 vs 現金」（spread 更大），同樣的權重誤差會造成遠大於此的偏誤。

### 3-3 成本權重 ≠ 市值權重

若「各投一半**成本**」，且持有期間 AVGO 未實現報酬 gA、VOO 為 gV，則實際市值權重 `w_AVGO = (1+gA)/((1+gA)+(1+gV))`：

| gA（AVGO 未實現） | gV（VOO 未實現） | 實際 w_AVGO | r_port | 反推本金 |
|---:|---:|---:|---:|---:|
| 0% | 0% | 50.0% | 3.198% | $3,127,373 |
| +50% | +20% | 55.6% | 3.368% | $2,969,159 |
| +100% | +30% | 60.6% | 3.523% | $2,838,608 |
| +200% | +50% | 66.7% | 3.709% | $2,696,342 |
| +300% | +60% | 71.4% | 3.855% | $2,594,187 |

**方向固定：高 beta 腿漲多之後，市值權重必然漂離成本權重、且組合報酬被低估 ⇒ 用成本權重會系統性「高估」本金。** 本案偏誤上限約 −17%（$3.13M → $2.59M）。

### 3-4 日期敏感度（口徑選錯一天）

| 日期 | AVGO | VOO | r_port | 反推本金 |
|---|---:|---:|---:|---:|
| 2026-07-21 | +2.205% | +0.830% | 1.518% | $6,589,640 |
| 2026-07-22 | +2.668% | −0.122% | 1.273% | $7,857,258 |
| 2026-07-27 | +0.340% | +0.025% | 0.183% | **$54,732,837** |
| 2026-07-29 | −2.780% | −1.517% | −2.149% | n/a（當日虧損） |
| **2026-07-30** | **+4.731%** | **+1.664%** | **3.198%** | **$3,127,373** |
| 2026-07-31 | +0.371% | +0.713% | 0.542% | $18,448,073 |
| 2026-08-03 | +0.758% | +1.420% | 1.089% | $9,183,792 |
| 2026-08-04 | +6.584% | +1.794% | 4.189% | $2,387,099 |

**同一個「賺 10 萬」的敘述，落在不同 session 上，答案橫跨 $2.4M ~ $54.7M（23 倍）。** 07-27 那列就是 §1-2 誤差放大的實體：r=0.18% 的分母把答案吹成 $54M——這個數字沒有任何資訊量，它只是在說「那天幾乎沒動，所以不可能是那天」。

反過來這是個**有用的推論工具**：知道 ΔP&L 且知道大致本金量級，可以**反查是哪一天**。

### 3-5 精度：輸入 1 位有效數字，輸出就只有 1 位

| ΔP&L | 反推本金 |
|---:|---:|
| $100,000 | $3,127,373 |
| $105,000 | $3,283,742 |
| $120,000 | $3,752,848 |
| $149,000 | $4,659,786 |

「超過 10 萬」字面涵蓋 10.0 萬 ~ 未達 15 萬 ⇒ **N ∈ [$3.13M, $4.69M]**。

⚠️ **自我修正**：我在對話中先報了 `$3,127,000`。7 位有效數字對應「盈虧金額已知到個位數」，但輸入只有 1 位。**正確報法是「約 $3.1M 起跳，上緣可到 $4.7M」。** 這是本篇要沉澱的具體行為修正。

### 3-6 附帶觀察：最末 bar 未定案

同一支腳本前後兩次執行（相隔數分鐘），**08-04 的 AVGO 收盤從 417.72 漂到 418.00**（VOO 708.79 → 708.91），07-30 及更早的 bar 則逐分不變。與 [[feedback_us_close_price_only_after_0400_tpe]] 同源——**最新一根 bar 在台北 04:00 前（含盤後修正窗口）不可當定案值**。本案標的日是 6 個 session 前的舊 bar，不受影響；但若要反推的是「昨天」，這條會直接進誤差項。

## 四、三個口徑陷阱（可攜帶的檢查清單）

### 4-1 只有市值權重進得了恆等式
「一半一半」在口語中極可能指**成本**。追問順序：
1. 是「各投一半錢」（成本權重）還是「現在市值各一半」（市值權重）？
2. 若是成本權重 → 需要兩腿的未實現報酬才能換算（§3-3）。
3. 偏誤方向已知：**成本權重會高估本金**，可先給區間 `[市值口徑下限, 成本口徑值]`。

ROMA 內部一律採市值權重，可作對照：
- `romasys/src/portfolio/parse_log.py:84-93` — `_mv()` 統一取 MV（xlsx `mv` / XML `market_value`），**取的是市值不是成本**
- `romasys/src/positions/ib_flex_parser.py:361-363` — `pct = d["market_value"] / nav * 100`，佔比分子分母皆為市值

### 4-2 日期先驗證再計算
- 先算候選日的 r_port，**r < ~1% 的日子直接排除**（它反推出的天文數字是分母病理，不是答案）。
- 負報酬日直接排除（與「漲」矛盾）。
- 美股 D 日收盤在台北 D+1 04:00 後才可查（[[feedback_us_close_price_only_after_0400_tpe]]）。

### 4-3 有效數字不得憑空增生
輸出精度 ≤ 輸入精度。「超過 X」是**單邊下限**，正確表述是區間或「≥」，不是點估計。

### 4-4 本方法不成立的四種情況
| 情況 | 為何失效 |
|---|---|
| 帳戶有槓桿 / 期貨 / 期權 | ΔP&L 不再 = NAV × 現股加權報酬（gamma、margin 佔用） |
| 當日有加減碼 | w_i 在盤中變動，恆等式的 w 未定義 |
| ΔP&L 含已實現損益或入金 | 分子被污染 |
| r_port 接近 0 | §1-2 誤差放大 |

## 五、結論與行動

1. **答案**：AVGO/VOO 各半、2026-07-30 單日賺逾 $100K ⇒ 本金 **約 $3.1M 起跳**（市值權重口徑）；考慮「超過」的上緣與成本權重偏誤，合理區間 **$2.6M ~ $4.7M**。
2. **可攜方法**：`N = ΔP&L / Σ(w_i·r_i)`，但先驗權重口徑（市值）、日期口徑（r 夠大）、精度口徑（有效數字）。
3. **判準**：`|r_port| ≳ 2%` 才做反推；低於此只回答「那天不可能是它」。
4. **行為修正（對我自己）**：反演類問題的輸出精度，一律砍到與輸入相同的有效位數，並以區間呈現單邊條件（「超過」「至少」）。

### 對我方作業的延伸用法
- **對帳反查**：brokerage_log 兩份快照的 NAV 差額 ÷ 當日組合報酬，可反查快照時點是否為收盤（呼應 [[feedback_holdings_ssot_brokerage_log]] 的「`parsed_at`／檔名日期都不是快照時點」問題）——若反推出的隱含 NAV 與 rr8 佔比表對不上，就是盤中快照。
- **口徑檢驗**：任何「某天賺/賠了多少」的敘述，都可用本式反查隱含部位規模，與已知 NAV 對照，作為一致性檢查。
