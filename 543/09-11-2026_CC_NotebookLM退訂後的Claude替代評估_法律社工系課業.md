# NotebookLM 退訂後，Claude 能不能接手 —— 給法律／社工系學生的功能對照與訂閱建議

> **定位**：2026-11-09 user 詢問。使用者不是 user 本人，是讀**法律系＋社工系**的女兒，課業用。NLM 付費層 11/20 到期，user 考慮改訂 Claude，擔心她已經習慣的 NLM 功能在 Claude 上找不到。
> **性質聲明**：這篇是**產品功能對照的操作知識**，不是實證研究，沒有樣本或對照組。標 `[未實測]` 的項目只來自一般認知，**沒有現查官網或實際操作確認**。
> **最大限制**：兩邊的價格、免費額度、語音摘要次數上限都會變動，**沒有現查**，以官網為準。

## 縮寫對照

- **NLM** = Google NotebookLM（user 口語稱「Gemini Notebook」）
- **CC** = Claude Code，終端機裡的開發者工具
- **Claude App** = claude.ai 網頁版＋手機 App
- **Pro** = Claude 個人付費方案
- **Projects** = Claude App 裡可以常駐上傳資料的專案功能
- **Artifact** = Claude App 產出的互動頁面（圖表、閃卡、測驗）

## S_1 框架：問題問錯了產品

第一輪我以 user 的交易 repo 為前提，拿 **CC** 去比 NLM。這對非開發者不適用：

- CC 是給寫程式的人用的終端機工具，學生不會用、也不需要用。
- **對應 NLM 的是 Claude App**。Claude App 和 CC 包在同一個 Pro 訂閱裡，所以「訂哪個」不需要選，要決定的只有她平常用哪個介面。

**教訓**：被問到「X 能不能取代 Y」時，先確認**誰在用、拿來做什麼**，再決定要拿哪個產品去比。

## S_2 功能對照（課業情境）

| NLM 功能 | Claude App | 說明 |
|---|---|---|
| 上傳講義／判決／論文，只根據來源回答 | ✅ | Projects：一科開一個專案，資料放進 Project knowledge |
| 摘要、讀書筆記、考前整理 | ✅ 較強 | 長篇推理和結構化整理是強項 |
| 申論題練習、案例分析、批改 | ✅ 明顯較強 | 出題 → 作答 → 指出漏掉的爭點；NLM 做不到這一步 |
| 心智圖 | ✅ | 叫它畫成 Artifact |
| 閃卡／測驗 | ✅ | 做成互動 Artifact |
| 讀 Google Drive 檔案 | ✅ | Google Drive 連接器 |
| 手機上使用 | ✅ | 有 App，也有語音對話模式 |
| **語音摘要（雙人對談 Podcast）** | ❌ | NLM 獨有。Claude 只有語音「對話」，不會產生 Podcast 檔 |
| **影片摘要** | ❌ | 沒有 |

**沒有替代品的只有語音摘要和影片摘要。** 技術上可以繞：叫 Claude 寫對談稿，再用 edge-tts、piper 之類的 TTS 轉成 mp3。但這要會用終端機，對學生不實際，品質也不如 NLM。

## S_3 法律系專屬風險：條號與字號

不管用 Claude 還是 NLM，引用的**法條條號、判決字號**都可能是錯的（AI 幻覺）。

- 交作業、寫報告前，一律到「全國法規資料庫」和「司法院裁判書查詢」核對原文。
- 這是使用習慣的問題，不是哪個工具比較安全。上傳原文、要求附出處可以降低錯誤，但不能讓錯誤歸零。

## S_4 結論與建議

1. **NLM 免費版不用丟。** 退掉的是付費層，NLM 本身有免費額度，語音摘要也在免費版裡 `[未實測：免費版次數與來源上限]`。
2. **組合建議**：
   - **Claude Pro**：理解、推理、寫作、練申論、整理筆記
   - **NLM 免費版**：只留著產生語音摘要，通勤時聽
3. **先試用再訂**：Claude 有免費版。讓她拿真的講義試一週（開專案 → 問答 → 出申論題），覺得夠用再升 Pro。Pro 是月訂，可以隨時停 `[未實測：台灣定價]`。
4. **判斷問句**：問她「NLM 裡最常按的是哪個按鈕？」
   - 最常按**語音摘要** → 維持 NLM 為主、Claude 只用免費版輔助
   - 最常用**問答或整理筆記** → 換成 Claude Pro 是升級
