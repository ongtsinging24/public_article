# debit 垂直價差「晚期」的拆腿經濟學 — 兩條損益平衡恆等式

> 2026-07-28 ｜ 實例：`SMH_BEPS_AUG26_575_520`（實倉，qty +5）
> 類型：方法論（常青）— 適用任何 debit vertical（BePS / BuCS）進入獲利區之後的處置決策

## 縮寫對照

## 1. 理論框架

### 1.1 一個常被忽略的相位轉換：debit spread 晚期會翻成「淨賣時間價值」

開倉時（兩腿皆 OTM／價平附近），長腿 extrinsic > 短腿 extrinsic → **net theta 為負**，時間是敵人。
但當標的走到**短腿履約價附近**時，狀況反轉：

- 長腿已 deep ITM → extrinsic 被壓縮到很小
- 短腿變成 ATM → extrinsic 達到最大值

此時 **net extrinsic 轉負（＝你淨賣出時間價值）→ net theta 翻正、net vega 翻負**。

> 這是本篇最重要的一句話：**「剩餘的獲利」在數學上就等於「短腿的 extrinsic」。**
> 拆掉短腿 ＝ 把自己的獲利引擎買回去，同時把 theta 從順風翻成逆風。

### 1.2 兩條損益平衡恆等式（可直接心算，不需模型）

設 debit BePS：long K_H put / short K_L put，width = K_H − K_L，現價 S，價差市價 V，短腿市價 P_short。

**(A) 「今天整組平掉」vs「抱到期」的平衡價**

```
到期價差 = K_H − S  （當 K_L < S < K_H）
令其 = V  →   S_hold_BE = K_H − V
```
S 若在到期時**高於**此價，今天平掉比較好；低於此價，抱著比較好。
→ 這把「要不要現在落袋」翻譯成一個**明確的反彈容忍度**，而不是心理價位。

**(B) 「買回短腿留單腿」vs「不拆」的平衡價**

```
不拆到期收：width                （若 S ≤ K_L）
拆後到期收：(K_H − S) − P_short
令兩者相等 →   S_legout_BE = K_L − P_short
```

**這條恆等式與 K_H 完全無關。** 它只說一件事：

> 你為了解放下方空間所付的錢（P_short），必須靠標的**再跌 P_short 這麼多**才賺得回來。
> 短腿越貴（＝IV 越高、越接近價平）→ 拆腿門檻越高。而「短腿最貴」的時刻，
> 恰恰就是「你最想拆腿」的時刻（標的剛殺到短腿）。**這是一個結構性的擇時陷阱。**

### 1.3 為什麼 ROMA 的 `Δnet` / `exp=` 看不出這件事

`option_delta.py` 只算 delta（`romasys/src/portfolio/option_delta.py:367` `delta_exposure()`；
spread 兩腿分解在 `_spread_delta_exposure`，語意定義見 `option_delta.py:250`
`BEPS (Bear Put, debit): long=max(K) put, short=min(K) put`）。
全檔**沒有** theta/gamma/vega（`grep -n "theta\|vega\|gamma" romasys/src/portfolio/option_delta.py` → 0 hits）。
持倉層唯一的 greeks 是券商 xlsx 逐腿 passthrough（`romasys/src/portfolio/portfolio.py:271,310`、
`romasys/src/portfolio/xlsx_parsers.py:107,333`，v3.56 加入），**未做 spread 淨額聚合**。

更關鍵的是：**BePS 在兩腿之間時 net gamma ≈ 0**（兩腿 gamma 幾乎抵銷），
所以 delta 對 spot 幾乎不動 → `Δnet` 這個數字對「部位進展」近乎失明（見 §3 表 C）。

## 3.5 width 上限是可以被突破的 —— 拆長腿的真實報酬結構

> 本節由 user 提問觸發（2026-07-28）：「若一週後 SMH 跌到 500 時先平長腿，到期又回到 520 以上，
> 獲利是不是會大於 $27,500？」**答案是：會，而且多 $11,367。**
> 這修正了 §4 舊版把「平長腿」僅以風險理由標為排除、卻沒講清楚它在報酬上可以破頂的缺漏。

### 3.5.1 為什麼上限會破

`width` 這個天花板**只在「兩腿同時走到到期日」時才成立** —— 它是短腿對消長腿的產物。
但在**中途**且 `S < K_short` 時，**長腿單腿的內含價值可以遠大於 width**：

```
S = 500 → 575P 內含 = 75  >  width 55
```

提前賣掉長腿 ＝ 解除對消 ＝ 解除上限；短腿的虧損被推遲到到期日才結算，
若標的在那之前彈回 `K_short` 上方，那筆虧損**永不發生**。

> **機制一句話：在低點領走長腿的內含價值，又在高點領走短腿的時間衰減 —— 同一段行情收兩次錢。**
> 前提是 V 型：**先夠低（長腿值錢）、後夠高（短腿歸零）**。這是純粹的路徑賭注。

### 3.5.2 平衡恆等式（第三條）

設節點2 賣出長腿實得 `L`：

```
B（拆長腿）到期損益 = L − max(K_short − S_T, 0)
A（不拆）到期損益   = width            （當 S_T ≤ K_short）

(C) B 勝 A  ⟺  S_T > K_short − (L − width)
(D) B 毛值歸零        S_T = K_short − L
```

本例 `L = 77.73`（S=500, 17 DTE, IV 55%：內含 75 + 時間價值 2.73）：
**(C) S_T > $497.27** ／ **(D) S_T < $442.27 轉負**。

### 3.5.3 三路徑對照（毛值，未扣入場 debit，可直接橫比）

| 到期 S | A：不拆抱到底 | B：T+7 平長腿留裸短 | C：T+7 整組平倉 |
|---:|---:|---:|---:|
| 560 | $7,500 | **$38,867** | $20,850 |
| 530 | $22,500 | **$38,867** | $20,850 |
| **520** | $27,500 | **$38,867** | $20,850 |
| 510 | $27,500 | $33,867 | $20,850 |
| **497** | $27,500 | ≈ $27,500（平衡） | $20,850 |
| 480 | **$27,500** | $18,867 | $20,850 |
| 450 | **$27,500** | $3,867 | $20,850 |
| 430 | **$27,500** | −$6,133 | $20,850 |

### 3.5.4 沒有免費午餐 —— 市場已把它定價成銅板

在節點2 當下（S=500、17 DTE、短腿 IV 58%）的風險中性機率：

| 事件 | 隱含機率 |
|---|---|
| 到期 S ≥ 497.27（**B 勝 A**） | **49.3%** |
| 到期 S ≥ 442.27（B 毛值不為負） | 82.1% |

**接近 50/50，這正是無套利下應有的結果。** 賠率結構：贏 +$11,367 ／ 輸（S=450）−$23,633
≈ **1 : 2.2 對你不利**，需勝率 >69% 才有正 EV —— 而你必須在標的剛從 522 殺到 500、
最恐慌的那一刻做出這個判斷。

**決定性反證 —— 買掉裸腿風險，超額利潤就消失：**
節點2 賣 575P（+77.73）同時買 490P（−19.17），維持 defined risk：

| 到期 S | 損益 | vs 滿額 $27,500 |
|---|---|---|
| ≥ 520 | $29,284 | **只多 $1,784** |
| ≤ 490 | $14,284 | **少 $13,216** |

> 一旦付錢買掉裸腿風險，市場立刻收走 **90% 的超額利潤**。
> 這直接證明：**$11,367 的超額報酬 ≡ 新承擔的方向風險的價格**，不是定價漏洞。

### 3.5.5 實務門檻（常在理論損益之前先咬人）

裸空 5 口 520P → 名目 **$260,000**，需裸賣權權限與保證金（Reg-T 概略 $50k+）。
且標的下跌時保證金**同向擴張**，可能在最壞的價位觸發強制平倉 —— 這條在觸發時往往
比 §3.5.3 的到期損益更早決定結果。

### 3.5.6 沉澱下來的判別式

> **debit vertical 的 width 上限，是「持有到期」這個假設的產物，不是結構的物理上限。**
> 任何提前解除兩腿對消的動作都能破頂，破頂幅度 = `L − width`，
> 而破頂的代價 = 你把「已封頂但確定」換成「未封頂但需路徑正確」。
> 判斷時**先算式 (C) 的門檻價，再問市場給那個門檻多少機率** —— 若接近 50%，
> 就代表這是純粹的方向賭注，該用方向觀點（而非「拆腿技巧」）來決定做不做。

## 4. 結論與行動

0. **width 上限是「持有到期」假設的產物，不是結構的物理上限**（§3.5）。三條恆等式構成完整判別組：
   `(A) K_H − V`（今平 vs 抱到期）／`(B) K_L − P_short`（拆短腿）／`(C) K_L − (L − width)`（拆長腿）。
   **算完門檻價後，一定要再問市場給那個門檻多少機率** —— 接近 50% 就代表它是純方向賭注。
1. **最大獲利點 = S ≤ K_short 於到期**，本例 SMH ≤ $520 於 2026-08-21 → $27,500 毛值。
   往下無額外報酬，**「跌更多」對這張卡沒有價值**（除非你主動拆腿去解除封頂，見 §3.5）
   —— 這點決定了它不該再被當成純避險加碼的理由。
2. **debit spread 進入獲利區後會發生 theta/vega 相位反轉**；判「要不要提早了結」時
   先算 net extrinsic 的符號，而不是憑「long premium 會被 theta 吃掉」的開倉期直覺。
3. **拆腿門檻恆等式 `S_BE = K_short − P_short`**，與長腿履約價無關。記這一條就夠。
   短腿最貴的時刻＝最想拆的時刻＝門檻最高的時刻，這是結構性陷阱。
4. **要落袋用「減量」不用「拆腿」**：減量保留 payoff 形狀，拆腿改變風險型態。
5. **執行面**：deep-ITM 長腿買賣價差 4.5% 寬（60.45/63.25）、當日成交僅 7 張
   → 逐腿平倉的滑價本身就是不拆腿的獨立理由；一律走 combo 單。
6. **提前指派**：短腿 ATM 時全是時間價值 → 指派風險 ≈ 0。
   僅當 S 跌到 ~$470 以下、短腿 extrinsic 歸零才需留意；屆時被指派等於提前領到接近滿額
   （有長腿對沖），但需具備交割 `K_short × 100 × qty`＝**$260,000** 的現金／保證金能力。

### 與既有慣例的辨析（非證偽）

[[feedback_inst_conviction_overrides_retail_cap]] 說「見 ⭐⭐ 機構 conviction + BCS 持倉 → 主動建議拆 short leg」。
**該條仍成立，適用相位不同**：那是 **debit spread 早期**（短腿仍 OTM、便宜、拆腿門檻低、
且解放的是尚未賺到的空間）。本篇處理的是 **晚期**（短腿 ATM、最貴、解放的空間已被 width 封頂）。
判別式就是 §1.2(B)：**`K_short − P_short` 距現價多遠**。門檻近＝早期可拆；門檻遠＝晚期別拆。
