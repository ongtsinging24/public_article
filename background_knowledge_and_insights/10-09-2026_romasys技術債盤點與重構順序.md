## 債項（依嚴重度）

### ① 沒有 packaging，全靠 `sys.path.insert` 樣板 🔴
- 無 `pyproject.toml` / `setup.py` / 根層 `requirements.txt`（只有 `tests/requirements-ci.txt`）
- 每個模組開頭 5–8 行 `_SRC_DIR = ...; if _SRC_DIR not in sys.path: sys.path.insert(0, _SRC_DIR)`
- 絕對 import 418 處（`from opportunities.x`）vs 相對 import 52 處混用
- 後果：IDE/pyright 解析不到、不能 `pip install -e .`、tests 也要重複樣板
- 修法：加 `pyproject.toml`（src layout 已就位）；CI 改 `pip install -e .`；一次 sed 掉樣板
- 風險：daemon 用 `restart_roma.sh` 起，要確認 systemd 環境有裝 editable package（見
  `reference_roma_daemon_stale_module_trap`：daemon 跑舊碼陷阱）

### ② `except Exception` 610 處，~90 處直接 `pass` 🔴
- 交易系統裡靜默吞例外 = 資料缺失時 signal 照樣產出。已知症狀：yfinance OI=0 當平倉、
  data_table 靜默凍結（memory 兩條 reference 都是這類）
- 最低要求：`pass` → `log.warning(...)` 帶 sym/來源；資料源類改明確 fallback 回傳
- 找法：`grep -rn -A1 "except.*:" --include="*.py" src/ | grep "pass$"`
- 與 area=靜默錯誤 的既有四張卡是同一族，本項是「掃全庫」而非個案

### ⑤ 函式內 import 678 處 🟠
- `socket_commands.py` 60、`sg_scan.py` 32、`tg_commander.py` 29、`roma_socket.py` 26
- 根因 a：`config.py` import 時硬性要求 `~/.roma_secrets.py`（CI 要 `cp config.example.py` stub）
