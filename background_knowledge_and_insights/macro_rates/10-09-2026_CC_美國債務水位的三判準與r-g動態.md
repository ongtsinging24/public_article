> **一句話**：$40T 是絕對數字，沒有決策含量；有含量的是三個比率

## 1. 理論框架

### 1.1 為什麼絕對數字沒有含量

$40T 這個數字在任何決策式裡都不出現。債務可持續性的核心恆等式是**比率的變化率**：

```
Δd  ≈  (r − g)/(1 + g) × d  −  pb
       └──────┬──────┘         └┬┘
        雪球項（自動）       政策項（國會決定）
```

其中 `d` = 債務/GDP。這條式子說：**債務比會不會爆炸，跟債務有多少兆完全無關**，
只跟 (a) 利率相對成長率、(b) 基本收支 兩件事有關。所以看到「$40 兆」的正確反應是
「換算成 d、r、g、pb 再說」，不是恐慌。

### 1.2 三個判準的分工（各答不同問題，不可互相取代）

| 判準 | 問的問題 | 觀察量 | 性質 |
|---|---|---|---|
| ①排擠 | 利息吃掉多少財政空間？ | 利息 / 稅收 | **當下已實現**，最硬 |
| ②動態 | 債務比會自己漲還是自己跌？ | r_eff − g | **機械性**，可外推 |
| ③定價 | 市場對財政風險要多少補償？ | 名目 − 實質 − BE 分解 | **前瞻但無方向 edge** |

⚠️ 常見誤用是拿 ③ 當進出訊號。③ 只告訴你「這波長端上行是哪一種故事」，
**不告訴你股票接下來會怎樣**（§4.3）。

### 1.3 分子口徑陷阱：123% / 101% / 96.8% 是三個不同分子

媒體同時流通三個數字，它們都對，但**分子不同**：

| 口徑 | 分子 | 水位 | 誰在用 |
|---|---|---|---|
| gross debt | $40.05T（含約 $8T 政府內部持有） | ~123% | 媒體標題、Treasury 即時計數器 |
| public debt | ~$32T（實際要在市場籌資的部分） | ~101%（FY 口徑） | **CRFB / CBO 主張的正確口徑** |
| public / GDP（本篇現算） | 2026Q1 債 ÷ 2026Q2 GDP | 96.8% | 存量除以更新的流量 ⇒ 偏低 |

**內部持有（社安信託基金等）不需要在市場上籌資、利息是政府付給政府**，
所以談「市場壓力/排擠」時用 gross 會系統性高估。談「政治承諾總額」時 gross 才對。
本篇一律標明用的是哪一個。

### 1.4 為什麼「日本 230% 都沒事」是錯誤類比

這是最常見的安慰式推論，但推不動：

| | 日本 | 美國 |
|---|---|---|
| 誰持有 | ~90% 本國人 + 日銀 | 約 1/4 由**外國人**持有 |
| 外部收支 | 經常帳長期**順差** | 經常帳**赤字**，需持續吸引外資 |
| 約束型式 | 內部再分配 | **必須以市場能接受的利率賣得掉** |

⇒ 美國的約束不是「還不出錢」（本幣舉債 + Fed 可為最後買家 ⇒ 技術性違約機率 ≈ 0），
而是「**在什麼利率下才賣得掉**」。這也是為何判準 ③ 存在。

## 3. 結果

### 3.1 原始水位

| 序列 | as-of | 值 | 說明 |
|---|---|---|---|
| `GFDEBTN` | 2026-01-01 | $39.07T | 季末；Treasury 即時值 **$40.05T @ 2026-08-18** |
| `FYGFDPUN` | 2026-01-01 | $31.45T | public debt |
| `GFDEGDQ188S` | 2026-01-01 | 122.59% | 官方 gross/GDP |
| `GDP` | 2026-04-01 | $32,486B | SAAR |
| `A091RC1Q027SBEA` | 2026-04-01 | $1,247B | NIPA 聯邦利息，SAAR |
| `FGRECPT` / `FGEXPND` | 2026-04-01 | $5,981B / $7,765B | NIPA 收支，SAAR |
| `DGS10` / `DGS30` / `DFII10` | 2026-09-04 | 4.78% / 5.24% / 2.43% | |
| `FYFSD` | FY2025 | −$1.775T | 財政年度赤字 |

### 3.2 判準 ①：排擠 —— **已觸 1991 峰值，這是唯一已經觸線的指標**

| 口徑 | 計算 | 值 |
|---|---|---|
| NIPA 利息 / NIPA 收入 | 1,247 / 5,981 | **20.9%** |
| CBO net interest / receipts（FY2026 概估） | ~1.0T / ~5.5T | **~18%** |
| 歷史峰值對照 | FY1991 net interest/revenue | **18.4%** |
| FY2024 實績 | 882B / 4,920B | 17.9% |

⚠️ **兩個口徑不可混用**：NIPA 利息含政府內部付息、CBO net interest 已扣除，
差約 2–3pp。引用時必註明哪一個 —— 這是「利息佔比 18% 還是 21%」爭論的全部來源。

**判讀**：1990s 靠降息 + 科技景氣把這個比率從 18.4% 壓回 6–7%；這次沒有同等的利率下行空間。
CBO 預估 2036 年 net interest 到 **$2.1T**（超過國防 + Medicaid 總和）。

### 3.3 判準 ②：r − g —— **反直覺：目前雪球項是負的，債務比在自我壓縮**

| 量 | 值 | 註 |
|---|---|---|
| 名目 GDP YoY (g) | **+6.56%** | 2025Q2 → 2026Q2 |
| 有效債務利率 (r_eff) | **3.19%** | NIPA 利息 ÷ gross debt；含未滾動的舊低息債 |
| 新發債邊際利率 (r_new) | **4.78% / 5.24%** | 10Y / 30Y |
| **r_eff − g** | **−3.37pp** | |
| 赤字 / GDP（NIPA） | 5.49% | (7,765 − 5,981) / 32,486 |
| 利息 / GDP | 3.84% | |
| **基本赤字 (−pb)** | **≈ 1.65%** | 5.49 − 3.84 |

代回 §1.1 恆等式（用 public debt d ≈ 0.97）：

```
Δd ≈ (−0.0337 / 1.0656) × 0.97  −  (−0.0165)
   ≈ −3.07pp            +  1.65pp
   ≈ −1.42pp / 年
```

⇒ **以此算式，債務比應該在下降。** 這與「$40T 失控」的直覺相反，且是本篇最重要的發現。

**三個必須同時說的限定**：
1. **r_eff 是存量加權，會單向往 r_new 爬**。r_eff 3.19% vs r_new 4.78–5.24%
   ⇒ 每滾一批舊債，雪球項就往正號靠一步。**這是「已知會發生、只是速度問題」的緩慢劣化**，
   也是 $40T 這個故事的真正主軸 —— 不是總額。
2. **g = 6.56% 名目含通膨**。若名目成長回落到 4%，(r−g) 立刻縮到 −0.8pp，雪球項幾乎歸零。
3. ⚠️ **算式與觀測不符**：官方 `GFDEGDQ188S` 是 121.4 → 122.6 **上升**的，
   本節算出的卻是下降。差距來源＝ NIPA 赤字 ≠ 債務發行量（信託基金流量、現金管理、
   學貸重估等 financial-account 項目）。**本節結論只能當量級參考，不可當精算**，
   對帳列入 §6 待辦。

### 3.4 判準 ③：長端歸因 —— BE 不動、實質上行 ⇒ 財政故事

```
10Y 名目 4.78%  =  實質 (DFII10) 2.43%  +  BE 2.35%
```

BE 2.35% 貼近 Fed 目標、且近期不動；長端上行由**實質殖利率**帶動，
30Y 5.24% 相對 10Y 4.78% 呈陡化 ⇒ 分類為 **TP / 財政供給故事**，
而非通膨預期故事。依 [[19-08-2026_CC_US10Y水位地圖與同日beta的水位換檔]] §1.2 的三軸拆解，
這一類屬「**聯準會降息也救不到**」的型態（平坦化上行才是政策路徑重定價、Fed 轉向即可解）。

### 3.5 利率敏感度（量級，假設未驗證）

| 假設 | 值 |
|---|---|
| 假設 marketable debt WAM ≈ 6 年 ⇒ 年滾動量 | ≈ $32T / 6 ≈ **$5.3T/年** |
| 每 +100bp 的第一年增量利息 | ≈ **+$53B** |
| 五年累積（線性近似） | ≈ **+$265B/年** |
| 全額滾完後（極限） | ≈ **+$400B/年**（$40T × 1%） |

⚠️ WAM = 6 年是**未經現查的假設**，Treasury 官方 WAM 應從 MTS / Quarterly Refunding
現查再定稿。列入 §6 待辦。

## 4. 結論與行動

### 4.1 「算不算嚴重問題」—— 分兩種嚴重性，不可混談

| 類型 | 機率 | 說明 |
|---|---|---|
| **突發型危機**（違約 / 拍賣流標 / 美元失序） | **低** | 本幣舉債 + Fed 可為最後買家。真出事的觸發點多半是**政治性的**（債務上限攤牌、Fed 獨立性被侵蝕），不是算術性的 |
| **慢性侵蝕**（利息排擠、長端結構性墊高、財政空間耗盡） | **已在發生** | 這才是該定價的東西 |

**「嚴重」的真正含義**：下一次衰退時，美國沒有 2008 / 2020 那種財政火力了。
在 5.5% 赤字 + 120%+ 負債比的起點上再開一次 10% GDP 的財政包裹，市場會用長端殖利率投反對票。
⇒ 這是**左尾條件的惡化**，不是中位數路徑的惡化。

### 4.2 三判準現況總表

| 判準 | 現況 | 方向 |
|---|---|---|
| ① 利息/稅收 | 18–21%（口徑而定），**已觸 1991 峰值 18.4%** | 🔴 惡化中，無利率下行空間可解 |
| ② r_eff − g | **−3.37pp，仍有利** | 🟡 但 r_eff 單向往 r_new 爬 |
| ③ 長端 TP 分解 | 實質帶動、BE 不動 ⇒ 財政溢價 | 🟡 已在定價，非恐慌水位 |

### 4.3 對我方部位 —— **不可執行任何調倉**

1. 傳導路徑真實存在：長端實質殖利率地板抬高 ⇒ 高久期成長股估值天花板壓低。
   我方持倉集中在高 beta 半導體/軟體，這條是最直接的。
2. **但這條不可執行**。依 [[project_rate_beta_regime_no_forward_power]]：
   殖利率是**同日溫度計不是前瞻預警**（前瞻 18 組 CI 全重疊、24M beta 反號）。
   ⇒「因為債務問題所以減碼」是**空頭論述包裝的 null 訊號**，本篇不背書。
3. 可執行的只有**時點性的保護預算**：債務上限攤牌 / 季度再融資公告（QRA）/ 大型 30Y 標售
   前後，留意拍賣尾差與 TP 跳升 —— 那是保護該提前買的**時點**，不是方向訊號。
4. 若真要因財政風險降險，載體是 cash-equivalent（BOXX），
   不是 rotate to defensive equity（[[feedback_derisk_to_cash_not_defensive_equity]]）。

### 4.4 方法論外帶（跨主題可用）

* **看到任何「$N 兆」型標題，先問分母**。絕對數字在恆等式裡不出現。
* **同一概念的三個官方口徑並存時，先建口徑對照表再算**
  —— 同型陷阱已在 [[feedback_top_gamma_delta_exp_caliber_split]]、
  [[feedback_etf_basket_pe_is_not_sector_pe]] 各出現一次。
* **「別人更糟所以我們沒事」的類比必須逐項對齊約束條件**（§1.4 日本案例）。

則「雪球項仍為負、債務比自我壓縮」這個核心發現需要下修甚至翻號。
